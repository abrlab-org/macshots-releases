# macshots — Releases

Download the latest build of **macshots**, a free native macOS screenshot & screen-recording app.

### ⬇️ [Download the latest DMG](https://github.com/abrlab-org/macshots-releases/releases/latest)

Requires **macOS 15 (Sequoia) or later**, Apple Silicon.

---

This repository hosts **release binaries only**. The application source code lives in a
separate, private repository. macshots is licensed under **BSL 1.1** — free for personal
and company use.

> **Note on opening the app:** current builds are ad-hoc signed, not yet notarized by Apple.
> On first launch macOS Gatekeeper may say the app "cannot be opened." To run it, right-click
> (or Control-click) the app in Finder → **Open** → **Open**, or allow it under
> **System Settings → Privacy & Security**.
